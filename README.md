Token launch radar: every pre-token protocol in a sealed DefiLlama snapshot, ranked by implied value. The value model prices each protocol off the median market-cap / TVL of the live-token protocols in its own category, then adjusts for seven-day growth and for how long it has run with no token. The dashboard is a static page with no network: search, filter by category, sort, and a detail view per protocol with its model breakdown and a concrete farm plan.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
